# CTF15 - Electrum

## Opdracht

Op de laptop van Wouters is een bestand genaamd `default_wallet` aangetroffen. Uit onderzoek blijkt dat het om een Electrum software wallet gaat.

De verdachte wil het wachtwoord van de wallet niet geven. Probeer het wachtwoord van de wallet te vinden. Gebruik de informatie en bestanden bij deze opdracht.

## Wat lever je in?

Lever het gevonden Electrum-wachtwoord in.
